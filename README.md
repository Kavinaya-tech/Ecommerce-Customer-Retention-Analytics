# E-commerce Customer Retention & Revenue Analytics

## Project Overview
This project analyzes e-commerce transaction data to understand customer purchasing behaviour, repeat purchases, revenue trends, product category performance, and customer segments.

The analysis uses the Brazilian E-Commerce Public Dataset by Olist and Python-based analytics in Google Colab.

## Objectives
- Measure one-time and repeat customers.
- Calculate customer retention-related metrics.
- Analyze monthly item revenue.
- Identify top product categories by revenue.
- Segment customers using RFM analysis.
- Present findings through interactive visualizations.

## Tools & Technologies
- Python
- Pandas and NumPy
- Plotly
- Google Colab
- GitHub

## Key Analysis
1. Data quality checks and preprocessing
2. Delivered order and revenue analysis
3. Customer-level purchase summaries
4. Repeat customer analysis
5. Monthly revenue trends
6. Product category revenue analysis
7. RFM customer segmentation
8. Interactive dashboard visualizations

## Dataset
Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

Dataset source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Files
- `Ecommerce_Customer_Retention_Analysis.ipynb` — analysis notebook and visualizations
- `data/` — exported analysis tables, where included

## Important Metric Notes
Revenue is calculated from item prices for delivered orders and excludes freight. Repeat customer metrics reflect the purchases observed in the dataset period. RFM segments are rule-based analytical groups and are not predictions of future customer behaviour.

## Outcome
The project demonstrates data cleaning, data aggregation, customer analytics, revenue analysis, segmentation, and interactive visualization skills relevant to entry-level data analyst and data science roles.
